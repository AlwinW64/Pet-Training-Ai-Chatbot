# 🐾 PawTron – AI Pet Training Assistant

PawTron is an AI-powered pet training assistant that provides real-time guidance for dogs, cats, birds, reptiles, and small mammals.  
It uses Google’s Gemini API along with a custom knowledge base to deliver species-specific training tips and behaviour advice.

---

## 🚀 Features

- **AI Chatbot** that offers instant pet training recommendations.
- **Supports multiple species:** dogs, cats, birds, reptiles, hamsters.
- **Custom knowledge base** integrated through system instructions.
- **Streaming chat responses** for smooth, real-time replies.
- **Modern UI/UX:** Animated components, clean layout, responsive design.
- **Expandable architecture** for future image-based animal identification.
- **Hosted on GitHub Pages** for easy access and sharing.

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **AI Model:** Google Gemini 1.5 Flash  
- **API:** Google Generative AI JavaScript SDK  
- **Hosting:** GitHub Pages  
- **Data:** JSON, structured text  
- **Utilities:** Fetch API, ES Modules, Import Maps

## 📦 Project Structure

# 📚 How It Works

1. A structured knowledge base is loaded into the model as system instructions.  
2. User queries are sent to the Gemini API using `sendMessageStream()`.  
3. The model responds with real-time streaming output.  
4. Conversation history is managed in JS to maintain context.  
5. The chat interface updates dynamically with each message.
